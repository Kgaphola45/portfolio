02 · HOW I ACTUALLY WORK

My rules, learned the hard way.

Nobody taught me these in a course. The control room did.

  1. Answer like a human, then troubleshoot like a machine.First thirty seconds: who are you, what’s stopped, is anyone stuck? Then logs, then checks. People calm down when they feel heard — systems calm down when you follow the order.
  2. Write it down or it didn’t happen.Every fix gets a note the next shift can use. I’d rather over-document a weird weighbridge error than let someone rediscover it at 3am.
  3. Automate the boring part, but own the result.My PowerShell onboarding scripts and Excel reports save hours a week. If a script breaks something, that’s still my ticket. Automation isn’t an excuse.
  4. Escalate early, escalate clean.I’m Tier 1. When it’s Tier 2 territory — server health, deep network faults — I send logs, screenshots, what I tried, and the site’s status. No “please assist” with zero context.

03 · ONE SHIFT, HONESTLY TOLD

What a normal day looks like from my chair.

Not the highlight reel. The actual rhythm, most days since Feb 2025.

OPENING · QUEUE CHECK

Read the night’s notes before touching anything

I open the incident queue, Zabbix, and the handover doc. Anything red gets eyes first — data sync errors, a weighbridge that stopped posting, an app login failing at a gate. I check which ones are mine, which need Tier 2, which just need a callback.

MORNING · 75+ CONTACTS

Phones, tickets, TeamViewer, repeat

Password resets and username recoveries for web and on-site apps. Azure AD accounts for new haulier or colliery users, roles set right the first time. Weighbridge indicator tests, forensic transaction lookups when numbers don’t add up. Printer drivers at a remote site that only fail when there’s a queue. I aim for first-contact fix — my average sits around 92% — and when I can’t, I say so fast.

MIDDAY · REPORTS & PATTERNS

Turn the noise into a report someone reads

Performance trends, uptime summaries, the bottleneck that keeps almost-happening. I build these in Excel with formulas that do the boring counting, and I flag what’s worth a maintenance visit before it becomes an outage.

CLOSING · HANDOVER

Leave the next shift smarter than I started

Server health checks, alert queue triaged to SLA, open items written up with what I tried and what’s still weird. Then I log off knowing someone at a gate at midnight won’t have to start from zero.
