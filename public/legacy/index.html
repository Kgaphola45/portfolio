# Production PowerShell Automation · Emmanuel Kgaphola
# Automates Entra ID / Azure AD RBAC group mapping and ITSM audit log output
param (
    [Parameter(Mandatory = $true)][string]$UserEmail,
    [Parameter(Mandatory = $true)][string]$SiteCode,
    [ValidateSet('Staff', 'Operations', 'Management')][string]$Role = 'Staff'
)

$ErrorActionPreference = 'Stop'
Write-Host "[INIT] Provisioning $Role access for $UserEmail at site $SiteCode."

$roleGroups = @{
    'Staff'      = "ACL-Site-$SiteCode-StaffPortal"
    'Operations' = "ACL-Site-$SiteCode-Operations"
    'Management' = "ACL-Site-$SiteCode-Management"
}

try {
    $adUser = Get-AzureADUser -ObjectId $UserEmail
    $targetGroup = Get-AzureADGroup -SearchString $roleGroups[$Role]
    Add-AzureADGroupMember -ObjectId $targetGroup.ObjectId -RefObjectId $adUser.ObjectId
    Write-Host "[SUCCESS] Added $UserEmail to $($targetGroup.DisplayName)"
} catch {
    Write-Error "[FAIL] Provisioning aborted: $_"
}

Four rules learned in the help desk trenches

High-volume support and strict governance audits boiled down to four non-negotiables.

Rule 01

Human first, machine second

In the first 30 seconds: who is impacted, what system failed, and what is the business risk? Panic drops when people feel heard; systems recover when you follow calm diagnostics.

Rule 02

No ticket, no existence

Every check, alert, build, and patch must have an Odoo ticket with log evidence and a verified rollback plan. Touching production without a ticket is gambling, not support.

Rule 03

Automate misery, own the script

My PowerShell scripts save hours of manual entry every week. But if my script causes a hitch, that is my ticket to fix. Code is leverage, never an excuse.

Rule 04

Kill causes, not symptoms

On Tier 1, a quick reboot gets the queue moving. On Tier 2, rebooting without reading the event logs just schedules tomorrow’s outage. Find the root cause and fix it once.

“Uptime isn’t a vanity metric on a slide deck. It’s branch staff and operations running smoothly without interruption because the systems, networks, and databases actually work.”
